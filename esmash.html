E-SMASH 🏸

Indoor Sports Booking Web Application

About the Project

E-SMASH is a web-based indoor sports booking system designed to simplify court reservations, scheduling, and sports facility management for users. Many indoor sports facilities still rely on manual booking methods, making reservations inefficient and difficult to manage. E-SMASH provides a centralized booking platform where users can reserve courts, check schedules, and manage bookings through a user-friendly web interface.

Features

  • Online Court Reservation
  • Online Coach Reservation
  • Real-time Booking Management
  • User Authentication
  • Coach Booking Dashboard
  • Admin Booking Dashboard
  • Responsive Web Interface

Technologies Used

HTML CSS PHP MySQL Sublime Web Design UI/UX
